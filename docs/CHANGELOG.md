# MEIMS Changelog

All notable changes to MEIMS will be documented in this file.

## [0.1.0] - Initial Release

### Project Initialization

- Established project vision for municipal monitoring and evaluation.
- Defined enterprise-grade architecture for backend, frontend, and data services.
- Created foundational documentation for system architecture and database schema.

### Backend Setup

- Set up Django REST Framework backend structure.
- Implemented custom user model with JWT authentication foundation.
- Defined RBAC entities, audit logging framework, and standardized API response handling.
- Configured application settings, middleware, and core app registration.

### Frontend Setup

- Set up TypeScript React frontend with Vite.
- Implemented reusable authentication components and protected routing.
- Built initial UI framework for login, password workflows, and onboarding pages.

### Authentication Foundation

- Designed secure authentication flow with JWT access and refresh tokens.
- Documented API contracts for login, logout, refresh, profile, change password, and reset workflows.
- Added support for future password reset and email-based notifications.

### Future Release Template

- Added placeholder sections for future minor and major release notes.
- Created roadmap for business module development and deployment.
